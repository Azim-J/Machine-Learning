HousingData.csv contains the median values of houses along with features like the crime rate, the tax rate, the amount of industrialized area, etc.

Housing_Data_Analyzer.ipynb analyzes that dataset, finding outliers and helping determine what features are useful

Housing_Value_Predictor.ipynb predicts the median house values based on the dataset using various different models, such as a linear regression, a decision tree, and a random forest, and outputs the loss of the model.
